# Security reports

Report suspected vulnerabilities privately to **raduself.oficial@gmail.com**. Include the app version, Windows version, affected feature and minimal reproduction steps. Do not include passwords, private keys, personal documents or complete application inventories. Avoid publishing sensitive details in a public issue before the maintainer has assessed the report.

Only the current development version is maintained. There is no guaranteed response time. No signing certificate has been issued to this project yet.

## Raportare

Trimite problemele de securitate la adresa de mai sus, cu versiunea aplicației și pași minimi de reproducere. Nu include parole, chei sau documente personale.
