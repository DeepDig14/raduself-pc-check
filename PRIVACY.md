# Privacy / Confidențialitate

RADUSELF PC Check processes RAM usage, drive capacity, names and memory usage of desktop applications, installed desktop application names/publishers, and temporary-file metadata locally to provide its features. It does not upload this inventory, run periodic scans, include advertising, or include telemetry.

The selected language is saved locally in `%LOCALAPPDATA%\RaduSelfPCCheck\language.txt`. User-requested copying of catalog commands uses the Windows clipboard; other applications with clipboard access may read it. Do not send personal files or inventories when reporting an issue.

Buttons can open Windows settings, Windows Security or system tools. Their own data handling and network activity are controlled by Windows and any installed security provider. The optional donation dialog displays bank information and can copy the IBAN; it does not process payments.

Administrator mode is requested only through explicit actions. System cleanup uses a separate elevated window and does not target the administrator account's personal TEMP. Files are deleted only after confirmation; deletion is permanent and bypasses the Recycle Bin.

## Română

Datele RAM, discurile, aplicațiile instalate/deschise și metadatele fișierelor temporare sunt prelucrate local. Aplicația nu trimite inventarul către un server, nu include reclame sau telemetrie și nu rulează scanări periodice. Limba se memorează local. Copierea unei comenzi sau a IBAN-ului folosește clipboardul Windows. Setările și instrumentele Windows deschise au propriile reguli de prelucrare a datelor. Donația este opțională și nu se efectuează plăți în aplicație. Curățarea poate șterge definitiv fișiere după confirmare. Nu trimite fișiere personale în sesizări.
